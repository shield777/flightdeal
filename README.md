# 최저가 항공권 (flightdeal)

아이폰·아이패드에서 쓰는 항공권 최저가 웹앱이에요. 설치나 서버 없이 브라우저에서 돌아가고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

주소: `https://shield777.github.io/flightdeal/` (처음 설정은 [SETUP.md](SETUP.md))

## 기능

| 기능 | 내용 |
| --- | --- |
| 월별 최저가 | 출발은 서울(인천·김포) 고정, 직항만. 나라·도시·기간·박수·인원을 고르면 달마다 기록된 최저가(1인 왕복), 날짜·몇 박, 항공사, 가격 추이 |
| 날씨·시기 | 목적지별 우기·건기, 최근 10년 평균 강수량·비 오는 날·최고기온(Open-Meteo 관측), 한국 공휴일·방학 |
| 바로가기 | 그 날짜로 구글 항공권·네이버 항공권·스카이스캐너·항공사 직판 열기 |
| 프로모션 탭 | 베트남·일본 LCC 특가를 항공사별로 정리. 제주항공·트리니티항공·비엣젯은 공식 홈페이지 이벤트를 매일 직접 확인, 나머지는 뉴스 기사 제목 그대로(출처 표시). 추정·계산 없이 원문에 적힌 내용만 |
| 카드 할인 | 우리·현대·신한 카드 할인 소식(공식·뉴스) 모음, 내가 등록한 할인 규칙을 가격에 반영 |
| 특가 알림 | 새 공식 이벤트·특가 기사를 아이폰(ntfy 앱)으로 알림 |
| 가격 하락 알림 | 목표가 이하, 30일 평균보다 15% 이상 하락, 기록 최저가일 때 알림 |

## 파일 구성

```
index.html              화면
css/base.css            공통 디자인 (밝은/어두운 모드 자동)
css/flights.css         항공권 화면 디자인
js/flight-core.js       목적지·기후·항공사·공휴일 데이터와 계산 ← 목적지·항공사 목록은 여기서
scripts/airline-events.js 항공사 공식 홈페이지 이벤트 읽기 (제주항공·트리니티항공·비엣젯)
js/flights.js           화면 동작
scripts/flight-check.js 매일 가격·특가·카드 할인 확인 + 알림 (GitHub Actions가 실행)
.github/workflows/      매일 아침 자동 실행 설정
data/watchlist.json     매일 추적할 노선 목록
data/*.json             매일 쌓이는 가격·프로모션 결과 (자동으로 바뀌어요)
```

## 컴퓨터에서 미리 보기

```
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 열어요.
