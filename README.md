# 최저가 항공권 (flightdeal)

아이폰·아이패드에서 쓰는 항공권 최저가 웹앱이에요. 설치나 서버 없이 브라우저에서 돌아가고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

주소: `https://shield777.github.io/flightdeal/` (처음 설정은 [SETUP.md](SETUP.md))

## 기능

| 기능 | 내용 |
| --- | --- |
| 월별 최저가 | 출발지·나라·도시·기간(예: 나트랑, 2027.1~10)·여행 일수·인원을 고르면 달마다 최저가(1인 왕복), 날짜·몇 박, 항공사·직항 여부, 보통 가격 대비 할인율, 가격 추이 |
| 수하물 | 항공사 기준으로 포함/미포함/확인 필요를 보여 주고, 15kg을 넣었을 때 가격(추정)으로 비교 |
| 날씨·시기 | 우기·건기·장마·태풍, 최근 10년 평균 강수량·비 오는 날·최고기온(Open-Meteo), 한국 공휴일·성수기, 구매 적기 |
| 바로가기 | 그 날짜로 구글 항공권·네이버 항공권·스카이스캐너·항공사 직판 열기 |
| 특가 알림 | 매일 아침 항공사 특가 뉴스를 확인해 아이폰(ntfy 앱)으로 알림, 특가가를 왕복+수하물로 바꿔 보통가와 비교 |
| 카드 할인 | 우리·현대·신한 카드 할인 소식 모음, 할인 규칙을 등록하면 가격에 반영 |
| 가격 하락 알림 | 목표가 이하, 30일 평균보다 15% 이상 하락, 기록 최저가일 때 알림 |

## 파일 구성

```
index.html              화면
css/base.css            공통 디자인 (밝은/어두운 모드 자동)
css/flights.css         항공권 화면 디자인
js/flight-core.js       목적지·기후·항공사 수하물·공휴일 데이터와 계산 ← 목적지·수하물 기준은 여기서
js/flights.js           화면 동작
scripts/flight-check.js 매일 가격·특가·카드 할인 확인 + 알림 (GitHub Actions가 실행)
.github/workflows/      매일 아침 자동 실행 설정
data/watchlist.json     매일 추적할 노선 목록
data/*.json             매일 쌓이는 가격·프로모션 결과 (자동으로 바뀌어요)
```

## 컴퓨터에서 미리 보기

```
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 열어요.
