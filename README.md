# 최저가 항공권 (flightdeal)

아이폰·아이패드에서 쓰는 항공권 최저가 웹앱이에요. 설치나 서버 없이 브라우저에서 돌아가고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

주소: `https://shield777.github.io/flightdeal/` (처음 설정은 [SETUP.md](SETUP.md))

## 기능

| 기능 | 내용 |
| --- | --- |
| 항공권 검색 | 출발 서울(인천·김포) 고정, 직항. 도시·가는 날·오는 날·인원을 고르면 네이버·구글·스카이스캐너 검색 화면을 그 조건 그대로 열어 줌. 스카이스캐너 한 달 전체 보기, 땡처리닷컴(도시별 땡처리·오늘 오픈), 항공사 홈페이지·앱 바로가기 |
| 여행 시기 정보 | 고른 날짜의 목적지 우기·건기, 최근 10년 평균 강수량·비 오는 날·최고기온(Open-Meteo 관측), 겹치는 한국 공휴일·방학 |
| 프로모션 탭 | 전체 항공사(국적 대형·저가 + 베트남·일본 항공사) 특가를 항공사별로 정리. 2시간마다 자동(6~22시, 또는 [지금 확인]). 뉴스 기사만 써요: 본문까지 읽어 금액·할인율·코드·예약기간·탑승기간을 뽑고, 이 값이 같은 기사는 한 줄로. '다음 달·내달'은 기사 등록일 기준 날짜로, 시간대가 적힌 마감 시각은 한국 시각으로. 노선마다 가격·탑승기간이 다르면 고른 나라 노선 것만(없으면 할인율만·'노선마다 다름'). 할인율 높은 순. 추정 없이 원문에 적힌 내용만 |
| 카드 탭 | 우리·현대·신한 카드 할인 소식(뉴스) + 항공사 홈페이지의 카드·결제 혜택(제주항공·트리니티항공·비엣젯), 고른 나라에서 쓸 수 있는지 |
| 가격 하락 알림 | 목표가 이하, 30일 평균보다 15% 이상 하락, 기록 최저가일 때 알림 |

## 파일 구성

```
index.html              화면
css/base.css            공통 디자인 (밝은/어두운 모드 자동)
css/flights.css         항공권 화면 디자인
js/flight-core.js       목적지·기후·항공사·공휴일 데이터와 계산 ← 목적지·항공사 목록은 여기서
scripts/article-text.js 뉴스 기사 원문에서 날짜·기간·코드·가격이 든 문장 읽기
scripts/airline-events.js 항공사 홈페이지 이벤트 읽기 (카드 탭의 카드·결제 혜택만 씀)
js/flights.js           화면 동작
scripts/flight-check.js 프로모션·카드 확인(--promos) (6~22시 2시간마다 자동, 앱 [지금 확인] → GitHub Actions)
.github/workflows/      6~22시 2시간마다 자동 + 앱 버튼으로 실행
data/watchlist.json     프로모션 범위(나라·항공사) 설정
data/promos.json        프로모션 확인 결과
```

## 컴퓨터에서 미리 보기

```
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 열어요.
